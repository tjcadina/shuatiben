# 刷题本 · 智能刷题网页

一个纯前端的刷题小工具：上传试卷 → 自动归档科目 → 拆分为刷题模式 → 逐题作答判分 → 生成答题报告 → 错题自动进入错题集。

## 使用方式

1. 直接用浏览器打开 `index.html` 即可使用，无需安装依赖。
2. 点击「上传试卷」，选择 `.docx` / `.pdf` / `.txt` / `.md` / `.json` 文件，或直接粘贴试卷内容。
   若一个文件里包含多套试卷，会自动按试卷标题拆分为多套，可在导入前分别修改名称与科目。
3. 系统会根据题目内容自动识别科目，你也可以在导入前手动修改科目。
4. 在试卷库中点击「开始刷题」，逐题作答，提交后显示答案与解析。
5. 答完自动生成数据统计和答题报告，错题自动进入「错题集」。
6. 在「错题集」中重新作答：答对自动消除，答错继续保留。

所有数据保存在浏览器 localStorage 中，刷新页面不会丢失。

## 支持的试卷格式

### Word / PDF（自动提取文字）

- Word：支持 `.docx`，打开时自动提取正文文字；旧版 `.doc` 请先另存为 `.docx`。
- PDF：自动按版面提取可复制文字。扫描图片版 PDF（无文字层）无法直接提取，建议先 OCR 或转为 Word。
- 解析依赖 `vendor/` 目录下的本地组件，请勿删除 `vendor/mammoth.browser.min.js`、`vendor/pdf.min.js`、`vendor/pdf.worker.js`。
- 上传弹窗中内置「AI 出题要求」提示，可一键复制，方便按“年份 + 考试名称 + 《科目》”生成同类型模拟卷。

### 纯文本 / Markdown

```text
2026 数学周测卷

一、选择题
1. 1 + 1 = ?
A. 1
B. 2
C. 3
D. 4
答案：B
解析：基础加法。

2. 判断：0 是自然数。
答案：正确
解析：自然数包含 0。

3. 2 的平方等于？
答案：4
解析：2 × 2 = 4。
```

- 题目以 `1.` / `1、` / `Q1.` 开头。
- 选项以 `A.` / `B、` 等开头。
- `答案：` 后写答案，`解析：` 后写解析；二者写在同一行也可以。
- 可用 `[单选题]` / `[多选题]` / `[判断题]` / `[填空题]` 标记题型。
- 多选题答案可写 `ABD`、`A、B、D` 等。

### 先题目、后统一答案/解析的格式

题目全部罗列完后，再出现「参考答案 / 答案与解析 / 答案解析」等标题，后面按题号给出答案，系统会自动把答案与解析按题号回填到前面的题目上：

```text
1. 1 + 1 = ?
A. 1
B. 2
C. 3
D. 4

2. 哪个不是水果？
A. 苹果
B. 香蕉
C. 汽车
D. 桌子

参考答案
1. B
解析：基础加法。
2. C
解析：汽车不是水果。
```

也支持连续答案 `1-5 BACDA` 这类写法。

### JSON

```json
[
  {
    "question": "1 + 1 = ?",
    "options": ["1", "2", "3", "4"],
    "answer": "B",
    "analysis": "基础加法。"
  }
]
```

也支持 `{ "title": "试卷名", "subject": "数学", "questions": [...] }` 以及 `{ "papers": [...] }` 的多试卷结构。


## 手机端访问

1. 电脑与手机连接同一个 WiFi。
2. 在本项目文件夹打开终端，运行：`node server.js`（需电脑已安装 Node.js）。
3. 终端会显示类似 `手机局域网访问: http://192.168.x.x:8080` 的地址。
4. 手机浏览器打开该地址即可使用。

如果 Windows 防火墙弹窗，请选择“允许访问”。也可以把 `index.html / styles.css / app.js / vendor` 上传到 GitHub Pages、Netlify、Vercel 等静态托管，再用手机浏览器访问公网地址。

## 账号登录与云端同步（腾讯云开发 CloudBase）

侧边栏「备份/恢复」下方有账号卡片：注册/登录后，试卷、错题集与答题进度会自动同步到云端，手机与电脑登录**同一个账号**即可互通；答对消除的错题、删除的试卷也会正确同步到其它设备。

### 首次使用需要在控制台做一次配置

1. 在 [云开发 CloudBase 控制台](https://console.cloud.tencent.com/tcb) 打开本项目环境（环境 ID 已写在 `cloudbase-config.js` 的 `env` 中）。
2. **开启邮箱登录**：进入「登录授权」→ 开启「邮箱登录」，并按提示在「配置发件人」中填入发件邮箱（可用 QQ 邮箱 + SMTP 授权码），在「应用配置」中设置应用名称与自动跳转链接。
   - 若你的环境属于新版「身份认证 v2」，请在 `cloudbase-config.js` 中把控制台里对应的 `clientId` 填入（并在身份源中开启邮箱）。
3. **创建数据库集合**：进入「数据库」→ 新建集合，集合名填 `shuatiben_users`（类型选文档型）。
4. **设置集合权限（关键）**：进入该集合的「权限设置」，选择“自定义安全规则”，填写：
   ```json
   {
     "read": "auth != null && doc._id == auth.uid",
     "write": "auth != null && doc._id == auth.uid"
   }
   ```
   保存后，每个登录用户只能读写自己的那条记录（`_id` = 用户 UID），即可实现跨设备互通，同时不会读到别人的数据。

### 使用流程

- 未登录：数据只保存在当前设备（localStorage），功能完全不受影响。
- 注册：输入邮箱 + 密码（8-32 位、含字母和数字）→ 系统向邮箱发送激活邮件 → 点击激活后即可登录。
- 登录：登录后自动「拉取云端 → 与本机合并 → 上传」，之后每次答题 / 错题变化都会自动同步（约 1.2 秒防抖）。
- 退出登录：本机缓存数据保留；换账号登录会自动以“新账号云端数据”为准，不会串号。
- 同步规则：不同设备的新增试卷/错题会合并；同一道题/同一份进度保留最新修改；删除的试卷、答对消除的错题、完成的进度会同步清除到其它设备。

### 常见问题

- 登录/同步报「暂无读写权限」：按上面第 4 步设置集合安全规则。
- 报「集合不存在」：按第 3 步创建 `shuatiben_users` 集合。
- 注册后收不到激活邮件：确认发件邮箱 SMTP 已配置、查看垃圾邮件。
- 如果后续数据量很大（单份文档接近几百 KB），可联系开发者把云端存储拆分为多文档分片。
